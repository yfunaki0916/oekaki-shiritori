# おえかきしりとり

1台のスマホやパソコンを交代で回して遊ぶ、2人用のお絵かきしりとりです。
画面の文字はすべてひらがなで、小学1年生でも読めるようにしています。

## 遊び方

1. ホワイトボードに絵を描いて、答えをひらがなで入れる
2. 相手に渡す。相手は絵を見て答えを当てる（3回まで。1回外すと文字数、2回外すと答えの一部の文字がヒントで出る）
3. 交代して、答えの最後の文字から始まる絵を描く

- 「ん」で終わる言葉を入れた人の負け
- 同じ言葉は2回使えない
- 小さい文字は大きい文字として扱う（でんしゃ → 「や」）
- のばす音「ー」は1つ前の文字を使う（こーひー → 「ひ」）
- 濁点・半濁点で終わったときは、点を取った文字から始めてもよい（りんご → 「ご」か「こ」、らっぱ → 「ぱ」か「は」）
- 当てられないときは「ぎぶあっぷ」を2回押すと答えが出る
- 「これまでの え」を押すと、1枚目からの絵・答え・正解／不正解を途中でも見返せる
- 「おわる」を押すと、勝敗と描いた絵の一覧が出る
- 終わったゲームは、はじめの画面の「まえの しりとり」から後日見返せる

## 動かし方

`index.html` をブラウザで開くだけで動きます。インストールやサーバーは不要です。

## 記録について

終わったゲームは、遊んだ端末のブラウザの中だけに保存されます（直近20ゲームまで。容量が足りないときは古いものから消えます）。
別の端末からは見えず、ブラウザのデータを消すと記録も消えます。
