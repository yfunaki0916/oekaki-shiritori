# おえかきしりとり

1台のスマホやパソコンを交代で回して遊ぶ、2人用のお絵かきしりとりです。
画面の文字はすべてひらがなで、小学1年生でも読めるようにしています。

## 遊び方

1. 黒板に絵を描いて、答えをひらがなで入れる
2. 相手に渡す。相手は絵を見て答えを当てる（3回まで。2回外すと文字数のヒントが出る）
3. 交代して、答えの最後の文字から始まる絵を描く

- 「ん」で終わる言葉を入れた人の負け
- 同じ言葉は2回使えない
- 小さい文字は大きい文字として扱う（でんしゃ → 「や」）
- のばす音「ー」は1つ前の文字を使う（こーひー → 「ひ」）
- 「おわる」を押すと、勝敗と描いた絵の一覧が出る

## 動かし方

`index.html` をブラウザで開くだけで動きます。インストールやサーバーは不要です。
記録は保存されず、ページを閉じると消えます。
